`main.py` writes one funny line (1-200 chars, UTF-8) to `/output/entry.txt`:

> I bought a standing desk to be healthier, and now I stand in front of the fridge instead of sitting.

Run: `python3 main.py`
Local test: `ENTRY_OUTPUT=./output/entry.txt python3 main.py && cat ./output/entry.txt`
